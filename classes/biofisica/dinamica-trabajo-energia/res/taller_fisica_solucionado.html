Sección A — Análisis Dimensional
1 Energía mecánica: ET = ½mv³ + mgh² + μmgd. Identifique términos consistentes con [J] = [kg·m²/s²].

Término 1: ½mv³ → [kg]·[m/s]³ = kg·m³/s³  ✗ No es J

Término 2: mgh² → [kg]·[m/s²]·[m²] = kg·m³/s²  ✗ No es J

Término 3: μmgd → [adim.]·[kg]·[m/s²]·[m] = kg·m²/s²  ✓ Es J

Solo el tercer término es dimensionalmente correcto. La ecuación bien escrita es ET = ½mv² + mgh + μmgd.

3 En Y(t) = Y₀² + V₀y·t² − ½g·t², ¿cuáles términos tienen dimensiones de posición [m]?

Término Y₀² → [m²]  ✗ No es m

Término V₀y·t² → [m/s]·[s²] = m·s  ✗ No es m

Término ½g·t² → [m/s²]·[s²] = m  ✓ Es m

Solo el tercer término es correcto. La ecuación bien escrita es Y(t) = Y₀ + V₀y·t − ½g·t².

4 Verifique dimensionalmente T = 2π √(L/g).

[L/g] = m / (m/s²) = s²

[√(L/g)] = s

[2π·√(L/g)] = s  ✓ Coincide con [T] = s. La ecuación es correcta.

5 ¿Es correcta dimensionalmente P = m·g / l?

[m·g/l] = [kg]·[m/s²] / [m] = kg/s²  ✗ No coincide con [Pa] = kg/(m·s²)

La expresión correcta es P = m·g / A, donde A es el área [m²]:

[m·g/A] = kg·(m/s²)/m² = kg/(m·s²) = Pa  ✓

6 ¿Qué magnitud representa k en F = k·v²?

[k] = [F]/[v²] = (kg·m/s²) / (m/s)² = (kg·m/s²) / (m²/s²) = kg/m

k → densidad lineal de masa [kg/m]

Esta relación aparece en la fuerza de arrastre: k representa una característica del fluido y la geometría del objeto.

7 Verifique que P = F·v es equivalente a P = W/t.

[F·v] = (kg·m/s²)·(m/s) = kg·m²/s³ = W

[W/t] = J/s = (kg·m²/s²)/s = kg·m²/s³ = W  ✓ Ambas expresiones tienen dimensiones de potencia [W].

Sección B — Vectores
8 a⃗ = (−2, 5), b⃗ = (−2, −3). Calcule c⃗ = a⃗ + b⃗, |c⃗| y dir(c⃗).

a) c⃗ = (−2+(−2), 5+(−3)) = (−4, 2)

b) |c⃗| = √(16 + 4) = √20 = ≈ 4.47

c) θ = arctan(2/−4) = arctan(−0.5) ≈ −26.57°. Como cₓ < 0 y cᵧ > 0 → II cuadrante: θ = 180° − 26.57° = 153.43°

9 p⃗ = (4, −3), q⃗ = (−1, 5). Calcule r⃗ = p⃗ + q⃗, |r⃗| y θ.

a) r⃗ = (4−1, −3+5) = (3, 2)

b) |r⃗| = √(9 + 4) = √13 ≈ 3.61

c) θ = arctan(2/3) ≈ 33.69° — I cuadrante (rₓ > 0, rᵧ > 0 ✓)

10 u⃗ = (3, −4), v⃗ = (−1, 2). Calcule w⃗ = u⃗ − v⃗, |w⃗| y dir(w⃗).

a) w⃗ = (3−(−1), −4−2) = (4, −6)

b) |w⃗| = √(16 + 36) = √52 = ≈ 7.21

c) θ = arctan(−6/4) ≈ −56.31°. Como wₓ > 0 y wᵧ < 0 → IV cuadrante: θ = −56.31° (equivalente a 303.69° si se mide desde el eje x positivo en sentido antihorario)

11 v⃗ = (−3, −3). Halle magnitud, dirección y explique el error de la calculadora.

a) |v⃗| = √(9 + 9) = √18 = ≈ 4.24

b) La calculadora devuelve arctan(−3/−3) = arctan(1) = 45°, que corresponde al I cuadrante.

c) Pero vₓ < 0 y vᵧ < 0, por lo que el vector está en el III cuadrante. Corrección: θ = 45° − 180° = −135° (equivalente a 225° en sentido antihorario)

Regla: arctan solo devuelve ángulos en I y IV cuadrante. Para III cuadrante reste 180°; para IV cuadrante la calculadora ya devuelve el ángulo negativo correcto.

Sección C — Cinemática
12 Caída libre desde 2 m, t = 0,6388 s, V₀y = 0. Calcule g e identifique el planeta.

Y(t) = Y₀ − ½g·t²  →  −2 = −½·g·(0.6388)²

g = 2·2 / (0.6388)² = 4 / 0.408 = g ≈ 9.8 m/s² → Tierra

Referencia: g en otros planetas: Luna 1.6, Marte 3.7, Júpiter 24.8, Saturno 10.4, Venus 8.9, Mercurio 3.7, Neptuno 11.2, Urano 8.7 m/s².
