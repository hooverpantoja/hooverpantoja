# Hoover Pantoja

Sitio personal y académico con secciones de perfil, clases, investigación, publicaciones y CV.

## Estructura principal

- `index.html`: portada principal del sitio.
- `classes/index.html`: acceso a las clases.
- `classes/biofisica/index.html`: ruta principal de Biofísica.
- `classes/calculo/index.html`: ruta principal de Cálculo.
- `investigacion/index.html`: página intermedia hacia ResearchGate.
- `publicaciones/index.html`: página intermedia hacia Google Scholar.
- `cv/index.html`: página intermedia hacia el CV completo.

## Convención de rutas

- Las páginas públicas viven como `index.html` dentro de cada carpeta.
- Los nombres de carpeta usan slugs legibles en minúsculas y con guiones.
- Los `README.md` se reservan para documentación del repositorio, no para páginas web.
